About Project

Academic overview and linear algebra foundations behind SpectraGraph

1. Spectral Graph Connectivity Analyzer

Linear Algebra (BTech Computer Science)

SpectraGraph is an interactive academic software system developed for a Linear Algebra course in BTech Computer Science. It demonstrates how matrix representations of graphs and eigenvalue decomposition reveal structural graph properties—specifically graph connectivity, connected component counts, and natural graph bisections—and cross-checks spectral results against classical graph algorithms.

2. What is a Graph?

A graph G = (V, E) consists of a finite set of vertices (or nodes) V = {v1, v2, …, vn} and a set of edges E representing pairwise relationships between vertices.

  • Undirected vs. Directed: In an undirected graph, each edge {u, v} is symmetric (bidirectional), whereas in a directed graph an edge (u, v) has orientation from u to v.
  • Simple Graphs: A simple undirected graph has no self-loops (no edge from a vertex to itself) and at most one edge between any pair of distinct vertices. SpectraGraph models simple undirected graphs.

3. Graph Connectivity

A path between vertices u and v is a sequence of distinct vertices connected by edges in E. A graph is connected if there is a path between every pair of vertices; otherwise, the graph is disconnected.

Every graph partitions uniquely into maximal connected subgraphs called connected components. A connected graph has exactly k = 1 connected component, while a disconnected graph has k ≥ 2 components.

4. Adjacency Matrix (A)

For a graph with n vertices, the Adjacency Matrix A ∈ ℝn×n records which pairs of vertices are adjacent:

Aij = 1 if {vi, vj} ∈ E,   and   0 otherwise
  • Symmetric: Because edges are undirected, A = AT (Aij = Aji).
  • Binary: All entries are either 0 or 1 in an unweighted simple graph.
  • Zero Diagonal: With no self-loops, Aii = 0 for all i.

5. Degree Matrix (D)

The degree di = deg(vi) of vertex vi is the number of edges incident to it, computed as the row sum of A: di = ∑j=1n Aij.

The Degree Matrix D ∈ ℝn×n is a diagonal matrix containing vertex degrees along the main diagonal and zeros elsewhere:

Dii = deg(vi),     Dij = 0 for i ≠ j

6. Graph Laplacian (L = D − A)

The combinatorial Graph Laplacian is defined as the difference between the Degree Matrix and the Adjacency Matrix:

L = D − A
  • Symmetric: Since both D and A are symmetric, L = LT, guaranteeing real eigenvalues and orthogonal eigenvectors.
  • Positive Semi-Definite (PSD): For every vector x ∈ ℝn, xTLx = ∑{i,j}∈E (xi − xj)2 ≥ 0, so all eigenvalues satisfy λi ≥ 0.
  • Zero Row Sums: Each row sums to di − ∑j Aij = 0, meaning the all-ones vector 1 always satisfies L1 = 0.

7. Eigenvalues and Graph Structure

Ordering the Laplacian eigenvalues in non-decreasing order gives 0 = λ1 ≤ λ2 ≤ … ≤ λn. This spectrum encodes global topological structure:

Key Theorem: Multiplicity of λ = 0 in L equals the number of connected components k

Null Space Interpretation: A vector x lies in the null space ker(L) (i.e., Lx = 0) if and only if xTLx = ∑{i,j}∈E (xi − xj)2 = 0, which forces xi = xj across every edge. Hence, x must be constant on each connected component, so the dimension of ker(L) equals the exact number of connected components k.

8. Fiedler Vector & Algebraic Connectivity (λ2)

The second-smallest eigenvalue λ2 is called the algebraic connectivity (introduced by Miroslav Fiedler). A graph is connected if and only if λ2 > 0, and larger λ2 indicates stronger connectivity without tight bottlenecks.

The eigenvector v2 associated with λ2 is the Fiedler vector. Because v2 is orthogonal to 1 and minimizes the quadratic form xTLx / xTx, partitioning vertices by the sign of their entries (v2(i) ≥ 0 vs. v2(i) < 0) yields a spectral bisection that separates the graph into two sparsely connected groups.

9. Independent Verification Methods (BFS & Union-Find)

Floating-point eigenvalue solvers can encounter numerical near-zero tolerances on ill-conditioned or large graphs. To validate spectral component counts independently, SpectraGraph runs two exact combinatorial algorithms:

  • Breadth-First Search (BFS): Explores reachable vertices layer-by-layer from unvisited nodes, counting each traversal sweep as one connected component.
  • Union-Find (Disjoint-Set): Merges endpoints of every edge using path compression and union by rank/size, counting the remaining disjoint sets.

10. Mathematical Concepts Used

  • Matrices: Matrix representation of graphs (A, D, and L = D − A).
  • Eigenvalues & Eigenvectors: Characteristic decomposition Lv = λv and spectrum ordering.
  • Null Space (Kernel): Relating ker(L) and zero-eigenvalue multiplicity to connected components.
  • Symmetric Matrices: Spectral theorem ensuring real eigenvalues and positive semi-definiteness.
  • Orthogonality: Mutual orthogonality of eigenvectors (v2 ⊥ 1) enabling spectral bisection.
  • Graph Connectivity: Paths, components, algebraic connectivity (λ2), and combinatorial verification.
