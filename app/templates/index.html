About Spectral Connectivity Analysis

Spectral graph connectivity analysis investigates the structure of an undirected graph G = (V, E) through the eigenvalues and eigenvectors of its Graph Laplacian matrix L = D − A.

By spectral graph theory, dim(ker(L)) = k (the multiplicity of λ = 0 equals the number of connected components), while λ2 (algebraic connectivity) is positive if and only if the graph is connected.

SpectraGraph computes A, D, L, solves the symmetric eigenvalue problem (Jacobi rotation for small graphs, NumPy eigh for large graphs), verifies components via BFS and Union-Find, and partitions connected graphs using the Fiedler vector.
